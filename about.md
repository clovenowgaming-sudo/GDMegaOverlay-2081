# GD Mega Overlay (2.2081 port)

A Mega Hack style overlay for **Geometry Dash 2.2081** on **Android**, built on **Geode 5.11.2**.
Port of [GDMegaOverlay](https://github.com/maxnut/GDMegaOverlay) by maxnut and SpaghettDev.

**Mod By Vinz :3**

## What you get

- The original GDMegaOverlay window UI
- A small round **draggable button** on Android: tap it to open or close the overlay
- **Touch scrolling**: drag vertically inside a window to scroll (no mouse wheel needed)
- **Macrobot**: record, play, save and load macros (practice mode aware)
- **Video recorder** using the FFmpeg API mod: pick your codec, FPS, bitrate and scale
- **Hacks**: NoClip, Safe Mode, Show Hitboxes, Instant Complete, Anticheat Bypass, Layout Mode,
  Solid Wave Trail, No Death Effect, No Ghost Trail, No Spawn Effect, No Spider Dash, No Burst Effect,
  No Portal Lightning, No Camera Shake, No Camera Zoom, No Ending Animation, No Mirror Portal
- **Bypasses**: Icon, Main Levels, Timeout, Slider Limit, Vault, Treasure Room, Text Length, Character Filter
- **Creator**: Copy Hack, Object Limit Bypass

## Safe Mode

Using cheats (NoClip, Instant Complete, Anticheat Bypass, Main Levels...) turns **Safe Mode** on.
While it is on, nothing is saved: no progress, no percentages, no completions, nothing is sent to the leaderboards.
Instant Complete and Anticheat Bypass always force Safe Mode.

## Notes

- Recorder needs the **FFmpeg API** mod (installed automatically as a dependency).
- This is a port in progress. Some entries of the original menu are not ported yet.
